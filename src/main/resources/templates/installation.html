Install Reports Server

Complete these steps to finalize your instance setup.

Step 1: SMTP Configuration

Configure SMTP first so the installer can send the welcome email and future account notifications.

For Gmail/Microsoft accounts, use an app password. Usually port 587 + STARTTLS is recommended.

Step 2: Admin User Configuration

Create the first account. This user will have ADMIN role.

If enabled, the wizard will show a QR code after creating the admin account.
Scan this code with Google Authenticator, Microsoft Authenticator, or any TOTP app.
Enter the current 6-digit code from your authenticator app to finish installation.
