SMTP Configuration

Configure outgoing email for password reset links and security notifications.

Selecting a preset will auto-fill host, port, and TLS options.

How To Configure SMTP

1. Choose a preset (or keep Custom), then fill username and from email.

2. Paste your SMTP/app password and click Save SMTP Settings.

3. Send a test email before relying on forgot-password notifications.

  • Gmail and Microsoft accounts usually require an app password (not your account password).
  • Use port 587 with STARTTLS in most cases.
  • Set APP_BASE_URL so password reset links point to the correct server URL.
